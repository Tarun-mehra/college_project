# Page Development Rules

When adding a new page:

1. Place it inside the correct section directory.
2. Use an existing page structure as a reference.
3. Reuse the global header, navbar, breadcrumb and footer.
4. Use existing CSS components whenever possible.
5. Add new section CSS only when existing styles cannot handle the requirement.
6. Keep semantic HTML structure.
7. Make the page responsive.
8. Test navigation links after adding the page.
